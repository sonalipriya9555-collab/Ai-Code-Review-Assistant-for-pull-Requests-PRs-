About This Project

Built for an AI / Agentic AI hackathon demo.

🎯 What it does

Analyzes submitted code or Pull Request diffs and flags bugs, security vulnerabilities, performance bottlenecks and code-quality issues, with per-line explanations and suggested fixes.

🧩 How it works

The frontend sends code to a Node.js/Express REST API. A rule-based review engine analyzes the code today, with a clean extension point to plug in a real LLM provider later — no frontend changes required.

🚀 Why it matters

Faster, more consistent first-pass reviews mean human reviewers spend their time on architecture and design decisions instead of spotting eval() calls and empty catch blocks.
